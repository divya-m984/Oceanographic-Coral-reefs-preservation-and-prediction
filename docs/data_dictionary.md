# CoralSense Data Dictionary

> **DISCLAIMER — SYNTHETIC DATA**
> All observations in the CoralSense dataset are computer-generated by
> `src/data/generate_data.py`.  They do not represent real sensor readings
> and must not be used to guide actual coral reef conservation or marine
> management decisions.  All parameter ranges and correlation directions
> are approximations based on published literature.

---

## Column reference

### Identifiers and spatial columns

| Column | Type | Unit | Range | Description |
|---|---|---|---|---|
| `timestamp` | datetime | — | 2018-01-01 – 2024-12-31 | UTC observation timestamp. Generated uniformly over the study period. |
| `latitude` | float64 | degrees N | see per-region bounds below | WGS-84 latitude of the sensor deployment site. |
| `longitude` | float64 | degrees E | see per-region bounds below | WGS-84 longitude of the sensor deployment site. |
| `region` | object (str) | — | 4 categories | Named reef region. See region bounds table below. |

### Physical / oceanographic features

| Column | Type | Unit | Approx. Range | Description |
|---|---|---|---|---|
| `depth_m` | float64 | m | 0.5 – 40 | Sensor deployment depth below mean sea level. Shallow-reef systems only. |
| `water_temperature_c` | float64 | °C | 18 – 37 | In-situ water temperature. Bleaching stress begins around 28.5 °C in Indian Ocean reefs (Hughes et al. 2017). |
| `ph` | float64 | dimensionless | 7.60 – 8.50 | Seawater pH (total scale). Normal open-ocean value ≈ 8.1–8.3. Below 8.0 indicates localised acidification or eutrophication stress. |
| `salinity_ppt` | float64 | ppt (g/kg) | 27 – 45 | Practical salinity. Gulf of Kutch is hypersaline (36–43 ppt) due to high evaporation in a semi-enclosed basin. |
| `dissolved_oxygen_mg_l` | float64 | mg/L | 2.0 – 11.0 | Dissolved oxygen. Hypoxia stress occurs below ~4 mg/L. Normal reef water is 6–8 mg/L. |
| `turbidity_ntu` | float64 | NTU | 0.05 – 32 | Water column turbidity. Elevated turbidity reduces light penetration and larval settlement success. Log-normally distributed in the generator. |
| `light_intensity` | float64 | µmol photons m⁻² s⁻¹ | 5 – 2 200 | Photosynthetically active radiation (PAR) reaching the substrate. Computed from surface irradiance attenuated by depth and turbidity using a Beer-Lambert approximation. Coral compensation point ≈ 50 µmol m⁻² s⁻¹. |
| `current_speed_m_s` | float64 | m/s | 0.005 – 0.95 | Near-bottom current speed. Moderate currents (0.05–0.40 m/s) supply nutrients and carry larvae; strong currents can dislodge fragments. |

### Acoustic / structural features

> `sonar_backscatter` and `rugosity_index` are **structural indicators** only.
> They do not directly measure bleaching or disease.

| Column | Type | Unit | Approx. Range | Description |
|---|---|---|---|---|
| `sonar_backscatter` | float64 | dB (re 1 µPa) | −36 to −2 | Calibrated side-scan or multibeam backscatter intensity. Hard, complex reef returns higher (less negative) values (−10 to −3 dB). Soft sediment or mud returns lower values (−30 to −35 dB). Simulated from the latent structure index; NOT a proxy for bleaching. |
| `rugosity_index` | float64 | dimensionless | 1.0 – 4.8 | Surface rugosity derived from high-resolution bathymetry. 1.0 = flat (sand/rubble); ≥ 3.5 = highly complex three-dimensional reef structure. Correlated with hard substrate and structural quality; not with bleaching. |
| `hard_substrate_percentage` | float64 | % | 0 – 100 | Percentage of the surveyed area covered by hard substrate (live coral base, dead coral skeleton, rock). Key predictor of restoration suitability. |
| `acoustic_complexity_index` | float64 | normalised [0, 1] | 0.05 – 1.0 | Normalised Acoustic Complexity Index derived from passive acoustic recordings. Higher values indicate a richer, more diverse biological soundscape typical of healthy reefs with abundant fish and invertebrate communities. Correlated with coral cover; NOT a direct measure of bleaching or disease. |

### Biological observations

| Column | Type | Unit | Approx. Range | Description |
|---|---|---|---|---|
| `coral_cover_percentage` | float64 | % | 0 – 90 | Percentage of the benthic transect covered by live coral tissue. Healthy reefs: ≥ 40 %. Severely degraded: < 15 %. |
| `bleaching_percentage` | float64 | % | 0 – 100 | Percentage of visible coral tissue showing bleaching signs (loss of zooxanthellae). Driven primarily by thermal excess above 28.5 °C in the generator. |
| `disease_percentage` | float64 | % | 0 – 60 | Percentage of coral colonies displaying disease signs (e.g., white syndrome, black band disease). Driven by pH stress and low dissolved oxygen in the generator. |

### Target variables

| Column | Type | Classes | Description |
|---|---|---|---|
| `reef_health` | object (str) | healthy, stressed, bleached, severely_degraded | Ordinal reef health classification derived from a weighted composite stress score (see below). |
| `restoration_suitability` | object (str) | suitable, moderately_suitable, unsuitable | Restoration site suitability derived from a weighted suitability score (see below). |

## Label generation

### Reef health score

A composite stress score *s* ∈ [0, 1] is computed from seven normalised
feature components.  Lower score = healthier reef.

| Component | Weight | Normalisation formula |
|---|---|---|
| Thermal stress | 0.20 | clip((temp − 28.5) / 4.5, 0, 1) |
| pH stress | 0.12 | clip((8.10 − pH) / 0.55, 0, 1) |
| DO stress | 0.08 | clip((6.0 − DO) / 3.5, 0, 1) |
| Turbidity stress | 0.10 | clip(turbidity / 20, 0, 1) |
| Bleaching fraction | 0.25 | bleaching_pct / 100 |
| Disease fraction | 0.12 | clip(disease_pct / 45, 0, 1) |
| Low cover | 0.13 | clip(1 − coral_cover / 72, 0, 1) |

Gaussian noise (σ = noise_scale × 0.50) is added before thresholding.

**Thresholds:**

| Score range | Class |
|---|---|
| s < 0.28 | healthy |
| 0.28 ≤ s < 0.47 | stressed |
| 0.47 ≤ s < 0.66 | bleached |
| s ≥ 0.66 | severely_degraded |

### Restoration suitability score

A suitability score *r* ∈ [0, 1].  Higher score = more suitable.

| Component | Weight | Notes |
|---|---|---|
| Temperature stability | 0.15 | Best at 28 °C; penalty ±6 °C |
| pH acceptability | 0.12 | Prefer > 7.75 |
| Light adequacy | 0.10 | clip(light / 500, 0, 1) |
| Substrate quality | 0.22 | hard_substrate_pct / 100 |
| Current quality | 0.10 | Optimal ~0.18 m/s |
| Turbidity clarity | 0.12 | clip(1 − turbidity / 18, 0, 1) |
| Depth suitability | 0.09 | Prefer < 15 m |
| Coral proximity | 0.10 | clip(coral_cover / 65, 0, 1) |

Gaussian noise (σ = noise_scale × 0.45) is added before thresholding.

**Thresholds:**

| Score range | Class |
|---|---|
| r < 0.35 | unsuitable |
| 0.35 ≤ r < 0.63 | moderately_suitable |
| r ≥ 0.63 | suitable |

## Known limitations

1. All correlations are **linear or simple nonlinear combinations** of latent
   variables.  Real reef systems exhibit complex nonlinear ecological dynamics
   not captured here.

2. The **noise model is Gaussian**.  Field measurement errors often follow
   non-Gaussian distributions (e.g., instrument quantisation, fouling spikes).

3. **No temporal autocorrelation** is modelled.  Real sensor time series exhibit
   strong diurnal and seasonal cycles.

4. **Region-level heterogeneity** is captured via Beta-distributed latent
   variables.  Fine-scale spatial autocorrelation (e.g., depth gradients along
   a reef wall) is not modelled.

5. **Class proportions** are controlled by the scoring thresholds in
   `generate_data.py`.  Real reef surveys often show highly imbalanced class
   distributions differing from this prototype.
